1. The Internet

The Internet is a global network of interconnected computer networks that communicate using standard protocols such as TCP/IP.

  • ARPANET (1969) was one of the earliest packet-switching networks.
  • It connects computers, servers, smartphones, and other devices worldwide.

2. The World Wide Web (Web)

The World Wide Web is a collection of resources available via the Internet. It allows users to access interconnected pages through hyperlinks.

  • Invented by Tim Berners-Lee in 1989.
  • Uses technologies like HTML, HTTP, URLs, and browsers.

3. W3C — World Wide Web Consortium

The W3C develops and maintains standards for the Web, such as:

  1. HTML
  2. CSS
  3. Web accessibility
  4. Web architecture

4. Web Page

A web page is a single document available on the Web, usually made with HTML. Example: https://example.com/about.html

5. Website

A website is a collection of related web pages under a common domain, like https://www.example.com. It may contain:

  • Home page
  • About page
  • Contact page
  • Services page

6. Home Page

The home page is the main page of a website and provides navigation to other sections.

7. Index Page

An index page is the default page served for a directory, usually named:

  • index.html
  • index.php
  • index.htm

8. Landing Page

A landing page is designed for one purpose, such as:

  • Register for a course
  • Buy a product
  • Submit a form

9. Web Browser

A web browser is software used to access and display web pages. Examples:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

10. Web Server

A web server stores and delivers web resources to clients. Examples:

  • Apache
  • Nginx
  • Microsoft IIS

11. Web Domain

A domain name is a human-readable name used to identify a website, e.g. www.example.com, instead of an IP address like 93.184.216.34.

12. URL

A URL specifies the location of a resource and how to access it.

https://www.example.com/2024/samples/first.html

13. URI

A URI is a broader term; a URL is a type of URI. A URI identifies a resource, while a URL identifies and locates it.

14. HTTP

HTTP is the protocol used for communication between browsers and servers. It commonly uses port 80.

15. HTTPS

HTTPS is HTTP protected with security (TLS). It commonly uses port 443 and provides:

  • Encryption
  • Authentication
  • Data integrity

16. SSL , 17. TLS

SSL was an earlier security protocol. It has been deprecated and replaced by TLS.

18. HTML — HyperText Markup Language

HTML is the standard markup language used to structure web pages. Basic boilerplate:

<!DOCTYPE html>
<html>
  <head>
    <title>Web Page</title>
  </head>
  <body> ... </body>
</html>

19. IP Address

An IP address is a unique number that identifies a device on a network.

  • IPv4 example: 192.168.1.10
  • IPv6 example: 2001:db8::1

20. DNS

DNS translates domain names into IP addresses, e.g. www.example.com → DNS → 93.184.216.34

21. nslookup

nslookup is a command-line tool used to query DNS information, e.g. nslookup example.com

22. Search Engines

A search engine helps users find information on the Internet. Examples:

  • Google
  • Bing
  • DuckDuckGo

23. ChatGPT

ChatGPT is an AI system that generates responses to natural-language prompts, while a search engine mainly helps find existing information.

24. Hyperlinks

A hyperlink connects one resource to another, e.g. <a href="https://example.com">Visit Example</a>
